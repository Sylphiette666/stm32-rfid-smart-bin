# 桶盖及附件 PETG 最终打印工程

使用P2S_LID_PETG_FINAL_008.3mf，六件，原尺寸和安装结构保持，无锁紧机构。采用本机Bambu配置库的Generic PETG @BBL P2S完整继承参数，不是仅改材料名称。P2S 0.4mm喷嘴，0.08mm层高，0.16mm首层，外墙及顶面25mm/s，4墙，20%填充，5mm裙边，无支撑，喷嘴255℃、纹理PEI板70℃。预计3小时53分钟、26.4g。按工程打开，保持100%比例。

安装方法沿用同名Word66.17；其中PLA和0.12mm打印参数由本版本替代，旧材料的重量估算不作PETG称重结果。实际耗材品牌未提供，使用Generic PETG；打印前核对料盘建议温度。合页偏移、球头及真实装配尚未验收，“最终版”指本次材料和打印设置交付。没有进行承载试验。

同目录另有PETG合页小样工程，供试装使用。全部249层路径、6件原生3MF网格回读和尺寸保持检查通过；未发送到打印机。
