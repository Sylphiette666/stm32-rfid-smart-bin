# D06 电机固定片试配件

**当前优先使用[快速版](fast/README.md)**：只打印B约14分钟/2.7g；A/B/C同盘约27分钟/8.0g。0.28mm层高，槽尺寸、中心距及5mm试配厚度与下文原版相同。下文0.16mm/48分钟工程留作较细层高备选。

先打印本目录的 **P2S_D06_FIT_TEST_016.3mf**。一盘有 A/B/C 三块，约48分钟、9.8g PLA，P2S 0.4mm喷嘴。作为项目打开，保持100%尺寸和原朝向，重新切片；已保存0.16mm层高、3墙、15%填充、顶底5层、无支撑及无防翘边。这是尺寸试配件，不能用作正式承重支架或通电行驶。

用户最新实测：固定片为非金属、窄身11.5mm、厚2mm，电机夹持处18.5mm；固定片向下穿入，T形宽头留在上面。旧聊天的“金属”和11×2mm槽不作为当前实测数据。

| 试配件 | 两个窄穿槽的尺寸 | 板厚 |
| --- | --- | --- |
| A | 12×2.2mm | 5mm |
| B | 12×2.4mm | 5mm |
| C | 12×2.6mm | 5mm |

每件两个槽的中心距均为21mm；2mm厚固定片居中时，内侧净距19mm。实际净距会随槽内游隙变化；0.5mm总余量是待试配值，不是已验证的最终尺寸。中央较大的方孔仅用于减料，不是固定片插入口。字母所在面为上面。

1. 冷却取下，去除毛刺，不先锉大窄槽。从 B 开始，把两片固定片从字母面向下插入两个窄槽，检查宽头能贴住板面、不能穿透。
2. B太紧试C，B明显晃动试A。选择可轻推插入、晃动最小的一块；若三块都插不入，说明12mm槽长或打印误差也需修正，不硬压。
3. 把试配件垫高，使固定片下端悬空；电机放在下方两片之间，用原配螺栓试穿原安装孔，螺母只轻旋，不能靠拧紧强行拉弯固定片消除间隙。
4. 检查5mm厚区域是否遮住螺栓孔，电机是否顶住板底、安装孔能否自然对齐。若被挡住，就停止，不自行切固定片。
5. 回复所选字母、松紧、两个螺栓能否穿过、板厚是否挡孔及电机是否顶板。必要时拍卡住位置。

全部断电试装，不需要先装轮子。正式底板暂不开孔。试配通过后再定左右转接座、底板孔位和轮组/万向球高度。未完成实物配合、承重或寿命验证。

提供独立STL和STEP用于检查；优先打印3MF工程。网格封闭性、实体有效性、数字窄身通过性及CLI切片已检查，无切片警告；3MF不含可直接执行G-code，未向打印机发送任务。
