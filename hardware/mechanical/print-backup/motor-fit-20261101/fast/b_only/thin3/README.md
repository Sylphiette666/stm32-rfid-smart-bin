# B试配件减薄至3mm

**已由[3mm无字新版](plain/README.md)替代。**用户要求电机贴合面无字；下文及本层含字工程仅保留历史记录。

用户反馈宽度合适、板太厚，要求减薄2mm。本版按前次推荐的B件制作，将穿槽承托区域从5mm改为3mm，凸字仍高0.4mm。B件12×2.4mm槽、21mm槽中心距及28×36mm平面外形保持不变，已用实体布尔差验证。若用户实际试的是A或C，需沿用对应槽宽，不能默认此次B件已经验证。

打印 **P2S_D06_FIT_B_THICKNESS_3MM_FAST.3mf**：作为项目打开，保持100%比例及原排布，重新切片。P2S/0.4mm/PLA，0.28mm层高、首层0.20mm、2墙、10%填充、顶底3层，无支撑和防翘边。切片预计12分22秒，2.0g；含机器起止流程估计。实际切片板面层高3.00mm（0.20+10×0.28）。

冷却后从字母面向下穿入固定片；检查T头落座、原配两根螺栓能否自然穿过，以及电机是否顶板。断电轻力试装，底板仍暂不开孔。此件仅用于尺寸验证，减薄后不能作为正式承重件上车使用；正式转接座可在穿槽局部保留3mm并另设加强区域，须在试配通过后设计。

已检查单实体、封闭网格、孔槽数字通过性、XY几何不变及切片无警告；原生3MF与受测切片模型一致。没有实物测试新版3mm厚度，没有向打印机发送任务。
