# 当前使用：3mm厚无字电机试配件

打印 **P2S_D06_FIT_B_3MM_NO_TEXT_FAST.3mf**。沿用B件12×2.4mm穿槽、21mm槽中心距，板厚3mm；彻底取消凸字，顶底接触面均无文字，最高几何及实际切片高度均为3mm。用户要求最终电机安装件也不加文字，尤其不能在接触面加凸字或标牌；此前其他电子模块底座标牌不受此更改影响。

P2S/0.4mm/PLA，0.28mm层高、首层0.20mm、2墙、10%填充、顶底3层，无支撑和防翘边。作为项目打开，保持100%比例，重新切片后打印。预计12分21秒、2.0g，含切片器估计的机器起止流程。

无字版不再靠字母判断朝向：两面都是平面，任选一面作为上面；固定片从上往下插入两条窄槽，T头留在上面。中央大孔是减料孔。断电轻力试装，确认5mm减为3mm后螺栓孔是否露出、两根原配螺栓是否能自然穿入、电机能否平整落位。打印首层如有毛刺先去除，不要强行夹紧消除干涉。

这仍是尺寸试配件，不作为正式承重转接座。已检查实体、网格、XY配合轮廓不变、实际切片顶层为3.00mm及切片无警告；新版尚未实物试装。之前含字3mm/5mm工程保留归档，不再推荐本轮使用。
