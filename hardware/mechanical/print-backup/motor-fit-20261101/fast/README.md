# 电机固定片快速试配

优先先打 [B单件](b_only/P2S_D06_FIT_B_ONLY_FAST_028.3mf)，实际CLI切片估计13分50秒、2.7g PLA。B槽为12×2.4mm；合适就不必打印A和C。若要一次比较三种槽宽，选 [A/B/C同盘](all_three/P2S_D06_FIT_ABC_FAST_028.3mf)，预计27分04秒、8.0g。时间包含切片器估计的机器起止流程，实际以所用设备切片和运行情况为准。

两工程均为P2S/0.4mm/PLA，作为项目打开，保持100%比例和原排布，重新切片后打印。参数已保存：层高0.28mm、首层0.24mm、2墙、10%直线填充、顶底3层，无自动支撑和防翘边，外墙60/内墙150mm/s。保持打印机标准100%速度。

所有模型网格与0.16mm原版完全相同；保留12mm槽长、A/B/C槽宽2.2/2.4/2.6mm、21mm槽中心距、5mm板厚及字母。0.24+17×0.28=5.00mm，层高安排能落在板面名义高度。较粗层高仍可能改变实际孔槽手感，试配通过不等于正式承重件验证。正式件的局部打印工艺若改变，应复核配合。

打印冷却后，两片固定片从字母面向下穿过两条窄槽，T头留在上面。中央大孔只用于减料。垫高试件，断电放入电机，试穿原配螺栓；不强行夹弯固定片。反馈B是否能轻推到底、是否晃动、5mm板厚是否挡孔、两根螺栓能否自然穿过及电机是否顶板。底板暂不开孔。

快速件仅用于轻力尺寸试装，不上车承重、不通电行驶。两份工程均切片成功且无警告，交付的原生3MF模型与受测切片一致，不含G-code；未向打印机发送任务，尚未实物试装。
