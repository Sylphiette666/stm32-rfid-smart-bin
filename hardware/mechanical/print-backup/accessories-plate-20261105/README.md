## 打印注意

1. **不要旋转、不要自动摆放**。这些簧片/拨片是 1.64 / 3.2 mm 的薄件，当前姿态是之前在整盘上验证过的平放姿态；改成竖放会显著降低层间强度。
2. 0.16 mm 层高是给薄簧片留的：1.64 mm 的簧片有 10 层左右，弯折时不容易沿层断开；用 0.28 mm 只有 6 层，簧片会更脆。
3. brim 是 4 mm 外沿，拆的时候沿盘面平推，不要向上掰，避免簧片尖端被带起。
4. 这一盘不含铰链轴、螺钉。压框/拨片装好后按装配指南 B 阶段：先试合 → 金属 M3×30 轴穿铰链 → 装簧片与锚钉（M3×25/30/40 按模块高度选）→ 装刚性拨片，锁母留 0.1–0.2 mm 轴向间隙。
5. 定位簧片只负责定位，不要靠它承受开合力；受力件是刚性拨片 + 金属轴。

## 已验证 / 未验证

- 已验证：31 个对象与原始盘上的网格、姿态一致（只删除了 13 个作废对象）；切片 rc=0、无 warning、gcode 45 层、0 条支撑、31 个 brim、16.93 g；工程文件内 layer_height 0.16 / PLA / P2S / 纹理 PEI 均正确，且不含 gcode。
