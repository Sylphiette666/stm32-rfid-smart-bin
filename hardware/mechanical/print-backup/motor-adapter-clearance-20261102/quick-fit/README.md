# 电机固定座快速试配

两种电机固定座已使用相同的快速试配参数，尺寸保持避让版不变。其他零件维持原打印配置。

| 文件 | 内容 | 切片预计 | PLA |
| --- | --- | --- | --- |
| [LEFT单件](P2S_D06_LEFT_QUICK_FIT_028.3mf) | 另一件，固定耳分在两侧 | 19分38秒 | 4.99 g |
| [RIGHT单件](P2S_D06_RIGHT_QUICK_FIT_028.3mf) | 照片中四孔集中在一侧的座 | 20分03秒 | 5.21 g |
| [两件同盘](P2S_D06_PAIR_QUICK_FIT_028.3mf) | LEFT和RIGHT各一件 | 32分34秒 | 10.20 g |

如果RIGHT已打印或正在打印，只补打LEFT即可。两台空闲P2S可以分别打印两个单件；同盘文件与两个单件文件择一使用，避免重复。

全部为P2S/0.4 mm喷嘴/PLA：作为项目打开，保持100%比例和原朝向重新切片。0.28 mm层高、首层0.20 mm、2墙、15%直线填充、顶底各3层，无支撑、无防翘边，机器使用标准100%速度。外墙90 mm/s、内墙200 mm/s，仍受原耗材体积流量及冷却限制；温度和耗材流量上限未修改。

两件模型都与避让版在导出精度内相同，最大顶点差小于0.00001 mm。已核对各文件模型数量、原生3MF与受测切片的一致性、首层对象和床面范围；结果警告为空，已查看新增首层路径。

只用于检查固定片插入、轮子正常装入和全周是否摩擦，不用于整机承重或行驶。试配通过后正式件继续使用原4墙/40%填充配置。其他模块座、舵机支架、底板、上平台和桶壁的打印配置没有修改。实物间隙仍待试配。
