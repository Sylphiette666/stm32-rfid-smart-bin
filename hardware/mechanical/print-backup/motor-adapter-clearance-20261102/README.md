# 电机座轮胎避让试装版

只想先快速验证轮子能否装入时，用[左右座快速试配文件](quick-fit/README.md)：单件约20分钟，两件同盘约32分34秒。两种座采用同样的低填充试配配置，仅用于尺寸试配；其他零件保持原质量配置。

打印 [P2S_D06_CLEARANCE_TRIAL_PAIR_028.3mf](P2S_D06_CLEARANCE_TRIAL_PAIR_028.3mf)。包含左右两种座各一件，P2S、0.4 mm喷嘴、PLA，切片预计42分37秒、14.66 g。作为项目打开，保持100%比例、原朝向，重新切片后打印。

本版针对用户照片中轮胎碰到穿槽区外边的情况：穿槽本体由28×36 mm缩至28×30 mm，两侧各内收3 mm，相连的端部加强筋同步缩短。槽外侧承托边从6.3 mm减至3.3 mm。**3.3 mm是保留材料宽度，不是轮胎间隙；实际轮胎包络和轴向安装深度尚未测得。** 偏置固定耳仍向外延伸，整个零件的包围盒不等于30 mm。

两槽12×2.4 mm、中心距21 mm、承托厚度3 mm、宽头腔6 mm不变，四个螺丝耳的孔位和完整承托区域保留。电机贴合面无文字。原版和本版STEP布尔比较确认槽周关键区域、宽头空腔及螺丝耳材料保持；本次减少了外围材料，旧版“完整保留试配件材料”的结论不适用于本版。

## 打印与试装

1. 配置已设0.28 mm层高、首层0.20 mm、4墙、40%直线填充、顶底4层，平放、无支撑、无防翘边，使用标准100%速度。打印前清洁打印板。本件很小且平放，不需要为速度改成竖放。
2. 冷却后装原配固定片、电机和轮子，轮子必须装到正常深度，再手动转一整圈。轮胎、轮毂均不能摩擦蓝色座、固定片或螺母。不要用少插入轮轴的方式制造间隙。
3. 这是尺寸未实测条件下的避让试装版，不代表已经保证3–4 mm轮胎净隙。若仍干涉，保留完整装配状态标出接触位置，再改相应区域；不要继续削薄承托固定片的槽壁。
4. 先完成完整轮组干装，再确定底板安装位置。暂不按候选坐标钻底板；本版未经过承重或行驶验证。

原计划五金不变：两个座合计8颗M3×20低圆头螺栓、16片外径不超过6 mm/厚0.5 mm垫圈、8颗约4 mm高M3锁紧螺母；最终应按实物叠厚核对螺纹穿出锁紧圈。没有新增五金种类。
