# 易拆支撑验证版 — 0.28 mm（PLA 与 R3D PETG）

日期：2026-11-04。目的：回应“树形支撑这么密，细杆/细柱在拆支撑时会不会被拉断/碎裂”。

## 结论

- 风险确实存在，主要来自**支撑接触面粘得太牢**：原快打候选的支撑顶间隙只有 0.28 mm（一层），界面 2 层、间距 0.5 mm；细柱被树形支撑多面包住时，拆除可能带掉一层皮或掰断细柱。0.28 mm 层高的 PLA/PETG 竖直细柱本身层间强度也偏低，这是内因。
- 本验证版不改层高与主体参数（仍 0.28 mm、3 墙、10% 填充、同树形支撑），只把支撑改成“好拆”：顶/底间隙 **0.42 mm**（1.5 层）、界面 **1 层**、界面间距 **1.0 mm**、支撑与模型 XY 距离 **0.5 mm**、界面速度 60 mm/s。
- 切片实测：易拆版**反而略快、略省料**——两套均约快 25 分钟、省 12–13 g（界面层 2→1、间距 0.5→1.0 减少了界面用量，支撑主体几乎不变）。
- 支撑界面接触量（gcode 挤出长度换算的面积近似）下降：下半主体约 49%，上半集成主体约 21%。

## 拆支撑建议（比参数更重要）

1. 不要“拽树枝”。用剪钳沿支撑枝干分段剪断，最后垂直向下掰开界面；细柱附近留到最后处理。
2. 细杆是否危险先看方向：竖直打印的细柱最怕侧向拉扯；横向/斜向打印的杆件结实得多。先在 Studio 里转一圈，把最细的立柱/卡扣位置记下来。
3. 首件建议先用小试件（细柱+树形支撑）验证 0.42 mm 间隙能否干净脱落，再上 13 小时的主体。
4. PETG 自粘性比 PLA 强；若实打仍紧，可把顶间隙加到 0.56 mm、界面间距加到 1.5 mm 再切（本包未做）。
5. 若某根细柱是非承力装饰件、却总被带断，可在 Studio 里给该区域刷“支撑阻挡”局部取消支撑（牺牲一点悬垂质量换安全）。

## 注意

- 间隙加大后支撑“托举”略松，极陡悬垂下方可能出现轻微下垂；本验证中支撑路径与时间基本未变。
- 以上均为 Bambu Studio 切片预测，未实物打印验证；如确认采用，可并入正式交付包并同步手册/仓库记录。
