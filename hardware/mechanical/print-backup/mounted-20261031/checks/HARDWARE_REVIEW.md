# 新增模块固定件硬件清单

本表只计算本次新增模块夹具，不含原车架立柱、舵机及其余原装螺丝。螺钉长度均为头下长度，M3 使用普通粗牙 0.5mm 螺距。喇叭两耳的紧固方案仍需实物耳高确认。

所有M3螺钉均按ISO7380低圆头最大外径5.7mm、头高1.65mm审核，特别是9根铰链轴、22根座脚及2根降压载座螺钉，不可换成头高约3mm的圆柱头。铰链R3.4避空按此头型轴向长度设计，任意M3头型不保证能翻动。

## 装配方向

- 22个座脚：低圆头在座脚上方，座脚厚2.4mm；头下1片垫圈，底板下1片垫圈和普通六角螺母。M3×12按普通高2.4mm螺母计算，不能直接换高4mm锁母。头高1.65加0.5垫圈，总凸出2.15mm，低座压框下名义仍留0.25mm。
- 降压载座两颗M3×16：低圆头在3.2mm载座上方，锁母在5mm底板下面。高圆柱头或把锁母放到载座上方会侵入PCB下方间隙。
- 11根拨片轴、11根簧片锚：头和一片垫圈在5mm底板下面，另一片垫圈和锁母在上方。轴顶部留约0.1–0.2mm转动间隙；簧片锚钉固定6×6mm方头，不能压住12mm自由弹臂。
- 簧片头上必须用外径不超过6mm的小垫圈。不要在拨片与轴座之间另加普通圆垫圈，它会盖住半径2.8mm处的定位凸点。
- 9根铰链：中央三节耳总跨23mm，两端各一片小垫圈，M3×30配锁母。只消除多余轴向窜动，保持压框自由翻动。盖已为螺头和锁母做R3.4包络避空。
- M2.5螺母先放入降压座底部六角窝，再把载座固定到底板。M2.5×8不加垫圈，名义有效吃牙约1.8–2mm；换10mm会顶到底板，不能强拧。
- A1柱下M3×10名义入柱4.5mm，柱上M3×6经1.6mm PCB和垫圈后入柱3.9mm。先确认所用双通柱两端孔深。

## 必须用实物核对的项目

数字检查使用ISO7380头Ø5.7×1.65、垫圈Ø6×0.5、锁母Ø6.4×4包络，结果见同目录 hardware_review.json；它不能替代实物试装。

1. 0.8mm角点压边是否碰到实际排针塑壳、焊点或元件；USB线尾、SWD插头、TF弹出行程、插好杜邦线后的弯线空间尚未量到。背针尖距底板的名义余量：MCU/MCP 11mm、DFPlayer 12mm、稳压模块5mm。
2. A1已知含正反面总高度28mm，但未给正反面高度分配；10mm绝缘柱是否让开全部底面焊脚仍需实物核对。
3. 喇叭耳下表面距底板顶面的高度记作E、耳厚记作t。选定垫圈和锁母下，M3×30须满足E+t≤19mm；先让耳下螺母刚好接触耳片，再锁上方，不能压弯耳片。若为垫下螺母而抬高壳体并脱离2mm高定位唇，应停止强装并测耳高。
4. 电池名义76×40×20，托槽77.2×41.2，2mm EVA后顶面距底板顶面24.4，拨片底面24.6，留0.2限位余量。拨片只挡硬塑壳端边，不能压电芯。实际外皮误差、EVA压缩和端边形状需试合。
5. 电池右端导线从中央12mm开口偏负Y半边引出；建议线束位于电池中心局部Y=-5..+1mm走廊，避开右拨片整个旋转范围。开关两拨片时全程不接触导线后再固定走线。

尚未完成实物打印、承重、振动或耐久试验。夹具几何及紧固件包络通过，只表示数字装配检查通过。
