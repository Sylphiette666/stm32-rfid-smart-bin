# 2026-10-30 四件同盘与舵机支架托片

在PLA整片轻量版上新增P03舵机调节支架与P04调节托片。P03采用60×190×5mm立板、60×24×5mm整体底脚和双三角撑；P04为80×40×5mm，带后柱U形缺口。P02新增(40,180)/(70,180)两处Ø3.4固定孔，其余原四柱孔、板轮廓、5mm安装高度与轻量结构保持。

P03上端两条M3轨用于按实物制作的转接夹片，未假设SG90耳孔距；实际壳体/耳孔、输出轴与50mm机构轴距仍须M47—M49试装。托片默认原点相对P02为(0,170,5)，支架底脚相对托片为(0,16,5)，已核对后柱Ø10工具通道。两处板间固定共4套M3×16配垫片螺母。

四件同盘排布通过实体相交、全高度XY投影+12mm brim、256mm名义空间检查，brim边最小间隙约7.0mm，另避开后侧检测预留区。两块主板均侧立，支架底脚着床、托片平放。仅支持逐层打印，不是逐件打印的打印头净空排布。

实际使用官方Bambu Studio 02.08.02.61的P2S 0.4/Generic PLA配置完成切片并成功导出，CLI返回0。0.20mm、4道壁、30% gyroid、12mm brim、较慢外壁速度设置估算约25.5小时/550g；估算随实际配置变化，不是实物耗时或耗材保证。

原生待切片3MF保留四个独立物体、位置和逐层打印设置，重读边界逐一匹配，不含G-code；另保留通用几何3MF。CLI在原厂P2S结束脚本T65535处有解析提示，日志原样记录，未修改厂商脚本；用户应以实际设备与耗材在Studio重切片后打印。
