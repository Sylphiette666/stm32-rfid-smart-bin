# V2.1 制造资料核对（2026-09-29）

## 结论与使用范围

三份原始导出文件与已归档的嘉立创 V2.1 工程通过本次一致性检查。可将原始 Gerber ZIP 用于厂家 CAM/DFM 审核和裸板报价。贴片 BOM 尚未选择供应商料号，本包不是已经完成配料与贴装方向审核的 SMT 下单包。

## 文件怎么用

- 原始导出/：保留用户导出的 BOM、坐标和 Gerber 文件，字节未改。
- 整理后的代焊资料/SMT_BOM_84件_21种规格_待选料.xlsx：把相同参数和封装归并为 21 行，共 84 件。Comment 使用原 BOM 的 Value，不使用 SmartBin_SB_x 内部名称。LCSC Part # 黄色列待填写；Manufacturer Part 对芯片/MOS 保留设计中的型号，其余留空待选。尚未核验料号、库存或价格。
- 整理后的代焊资料/SMT坐标_仅顶层84件_mm.xlsx：只含 84 个贴片件，坐标单位 mm，层别 Top；保留导出文件的负 Y 和原旋转角，不做翻转或平移。平台导入时确认单位为 mm。负 Y 是原点定义导致的正常数值。
- 整理后的代焊资料/插件清单_24件_待确认代焊.xlsx：23 个排针/跳线座与 1 个接线端子。报价时确认插件焊接服务、料号和规格；不能直接算进 84 件 SMT。
- H1～H4 是安装孔，不采购、不贴装，已从代焊表中排除。
- 核对报告和 CAM 预览：用于说明检查范围、定位和复核。

## 已完成检查

1. 原 BOM 的 112 个位号、数量、Value 和封装与设计一致；坐标文件同样包含这 112 个位号，无缺失、重复。
2. 84 个贴片件均在顶层，其贴片中心、角度与工程记录一致。供应商机台的角度零位和极性方向仍须结合最终所选型号，在下单贴装预览中逐项确认。
3. 板框闭合，135 × 105 mm。250 个金属化孔（其中 125 个为过孔）与 4 个 3.2 mm 非金属化安装孔，共 254 个实际钻孔，坐标、孔径、孔属性与工程一致。
4. Drill_PTH_Through_Via.DRL 是主 PTH 钻孔文件中的 125 个过孔子集。原始嘉立创 ZIP 原样保留；人工 CAM 导入时不要把该子集再当作额外 125 个孔叠加。它不表示总孔数为 379。
5. 959 段原工程走线中，955 段在 Gerber 中逐段对应；其余 4 段长度均小于 0.003 mm，完整铜形状由相邻导线/焊盘覆盖。不是断线。已核对 342 个有铜焊盘中心及板框；顶底面预览已检查。
6. 钻孔解析器提示 G90 位于头结束标记后；已根据实际数值逐孔核对，未产生坐标偏差。

## 下单前仍需完成

- 为 21 种贴片规格选择具体供应商料号，逐项核对封装、额定参数及引脚定义。电容的耐压/介质、电阻容差/功率、绿色 LED 极性、F1 的快断特性均不能仅凭封装自动替代。

- U1 使用 TLV1117LV33DCYR；不自动替换为任意 1117 稳压器。
- 核对 D1、Q1～Q3、U1～U6 的极性、1 脚和平台贴装角度，再确认贴装预览。

## 工程与板子使用约束

核心板通过排线按 GPIO 名称连接，不能按普通 Blue Pill 插座位置直插。J3 仅接稳压 5 V。电机/舵机动力电源独立并共地；底板上的舵机接口只提供信号与地。接线和上电按之前的接线资料执行。
