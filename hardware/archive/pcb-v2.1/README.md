# V2.1 PCB历史方案

本目录保存先前的 PCF8574 底板方案，属于历史设计，不是当前 MCP23017 成品模块＋A1裸PCB手焊方案（见[当前入口](../../current-low-cost/README.md)）。

- `original-exports/`：用户在2026年9月28至29日从嘉立创EDA导出的工程、Gerber、BOM和坐标等文件。
- `kicad/`：从已归档V2.1修正版包提取的KiCad设计和封装库。
- `packages/`：保留原始工程包及制造资料包。
- `manufacturing/`：当时的一致性核对说明和待选料贴装文件。

KiCad源设计、嘉立创导出和后续现场修改的版本边界见各包说明，不能假定它们是已同步的最新版。贴装料号、极性、厂家DFM和实物上电仍需核对；旧记录不代表新一轮生产已经通过验证。
