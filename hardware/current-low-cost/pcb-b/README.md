# SmartBin B1 模块线束 PCB

本版使用 KiCad，替代面包板和原洞洞板。现有 STM32 核心板、MCP23017、TB6612、降压/稳压板及传感器仍作为独立模块，通过现有排针和按信号标注的杜邦线连接。电池、电机、舵机和 DFPlayer 供电使用接线端子与合适线径，不通过细杜邦线。没有改变现有模块的排针焊接方向。

工程入口：`kicad/SmartBin_B.kicad_pro`；电路板：`kicad/SmartBin_B.kicad_pcb`；完整原理图：`checks/SmartBin_B_schematic.pdf`。B1 与旧 A1 的制造文件不能混用。

`mechanical/SmartBin_B.step` 是用于底座空间检查的PCB装配参考模型，包含KiCad库的名义元件外形；它不是现有独立模块的实测模型。其原点为元件面左上角，STEP中y轴与屏幕向下坐标相反。模型已检查为有效实体。

## 板形与新增电路

- 双层，125×100 mm，1.6 mm 厚，1 oz 铜。正面左上角为坐标原点，x 向右、y 向下。
- 四个 Ø3.2 mm 非金属化安装孔中心：(5,5)、(95,5)、(5,95)、(95,95) mm；孔距仍为 90×90 mm。板右侧比 A1 多出 25 mm，外形不再是 100×100 mm；一体打印底座须按此包络复核，不能按旧草图直接打印。
- 七颗 SN74LVC1G17DBVR（U2—U8，SOT-23-5）处理六路红外 DO 和 DFPlayer BUSY。缓冲器不反相，输入可接 3.3 V 或 5 V 逻辑信号，应用范围限定为共地、0—5.25 V。
- 每路 1 kΩ 输入串联、10 kΩ 上拉、100 nF 就地去耦；电阻和电容为 0805。七颗 IC 加二十一颗 0805 无源器件需要贴片焊接，其余器件以直插为主。
- 接 MCP 的缓冲器由 3V3_EXT 供电；接 PB8、PA12 的两路由 3V3_CORE 供电。两路 3.3 V 不并联。
- 原急停三管电路、AHCT125 输出提升、超声波 Echo 分压、电池 ADC、DHT 适配接口、灯驱动适配接口保留。

## 接口变化

完整逐针接线见 `connector-map.csv`，共 190 个端点。方焊盘为 1 脚；PCB 自定义针序不等于商品模块针序，按模块丝印逐根连接。

| 接口 | B1 接法 |
|---|---|
| J6 | 1=5V_BUS、2=GND，专供 DFPlayer VCC/GND；SPK1/SPK2 只接喇叭 |
| J31 | 1=GND、2=DF_RX、3=DF_BUSY_RAW；BUSY 经 U8 后到 MCP GPA6 |
| J33 | 1=3V3_EXT、2=5V_BUS、3=GND；4—9=IR0_RAW—IR5_RAW |
| J33 信号对应 | 4→GPB0、5→GPB1、6→GPB2、7→GPB3、8→PB8、9→PA12；信号功能沿用 A1 |
| J34 | 三脚均为 GND，分别连接 MCP 的 A0、A1、A2，使地址为 0x20 |
| J35 | 1=3V3_CORE、2=GND；低功耗辅助逻辑口 |
| J36 | 1=3V3_EXT、2=GND；低功耗辅助逻辑口 |
| J37 | 1=5V_BUS、2=GND；低功耗辅助逻辑口 |

J33 上的两种电源是供选择的独立脚，不能同时接到同一模块 VCC。模块 DO 可以进入对应 RAW 输入，不再需要为这七路另搭分压。其余传感器必须遵守各自接口电压，不能把“RAW 支持 5V”推广到所有 GPIO。

外置 AO3400A 转接模块仍接 J28；DHT 双向电平转换成品模块仍接 J23（按选用供电决定 JP8）。这两块应使用已焊好的小模块，不需要面包板。MCP 地址地使用 J34，模块电源按逐针表分配；需要分线时使用绝缘线束分支或现有接线端子。

## 焊接与检查

先焊 U2—U8 和 0805，再焊低矮直插件、排针、端子、电容、U1 插座。U2—U8 的 1 脚对准封装标记；U1 使用 SN74AHCT125N，不用 74HC125 代替。按 BOM 的 DNP 列保留可选电阻空位，不能把所有焊盘全部装满。

断电核查无焊桥、两路 3.3 V 不短接、极性正确。先单独调整降压至 5.0 V，再分阶段接入逻辑和模块；按既有手册确认跳帽供电选择。上拉默认使断线输入为高，感应有效电平和断线行为仍要逐项核对。不同模块断电时不要继续从外部给其信号脚送电。

架空车轮验证急停、释放后不自动续跑，然后再接舵机和负载。原急停只关闭轮电机驱动，并不切断舵机电源；外部 3.3 V 失电时的硬件联锁能力沿用 A1 的限制。本版未实焊、未带载、未做温升或 EMC 验证。

## 校验与制造

`checks/` 保存 ERC、DRC、实际导出网表及 372 个连接管脚/8 个 NC 的逐脚核对。`review/design-audit.json` 核对改动端点、缓冲器原厂引脚、安装孔和原 33 段粗电源线。制造输出只有在最终检查通过后才打包为 `manufacturing/Gerber_RS274X.zip`；BOM 在同目录。

规则：0.20 mm 间距，常规信号 0.30 mm、局部 0.25 mm，过孔 0.8/0.4 mm，原动力主干 3 mm/分支 2 mm保留。低电流缓冲器供电脚采用短 0.30 mm 扇出连接本地去耦，不用于动力供电。双层板的局部回流绕行和原 C8 距离限制仍需实物验证；数字 DRC 通过不等于抗干扰认证。

使用的技能与资料：[mash KiCad skills](https://github.com/mash/kicad-skills)、[PCB-design 检查流程](https://github.com/Toaster496/PCB-design)、[TI SN74LVC1G17 数据手册](https://www.ti.com/lit/ds/symlink/sn74lvc1g17.pdf)。用户已改用 KiCad，本版没有执行 EasyEDA 检查。

## 舵机接线示意图

`diagrams/servo/servo_wiring.png`（同目录另有 A4 横向 `servo_wiring_A4.pdf`）给出 SG90 三根线的分工：红→`J5.1`（5V_BUS，22 AWG，主电流只走这一路）、棕/黑→`J5.2`（GND）、橙→`J20.1`（SERVO_SIG_5V，由 `U1 SN74AHCT125N` 把 PA0 的 3.3 V PWM 提升到 5 V，`R6` 10 kΩ 下拉）。原厂 3 芯延长线必须在配电处拆成电源、信号两路，整根插 `J20` 会把 5 V 灌进信号排针。图源 `diagrams/servo/build_servo_diagram.py`，数据来源与自检见同目录 `diagram-manifest.json`、`diagram-qa.json`（排版自检 0 重叠、导线 0 交叉、像素抽查通过）。该图是接线图，未做实物通电验证。
