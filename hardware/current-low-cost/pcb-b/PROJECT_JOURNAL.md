# B1 设计记录

2026-11-03：用户改用 KiCad，接受少量贴片器件；全部现有模块继续以排针和杜邦线外接，不改焊模块排针。继承 A1 已校核的动力分配、急停和 MCU 管脚；建立独立 `pcb-b`，未改写 A1。

采用七颗 SN74LVC1G17DBVR，分别处理六路红外输入和 DFPlayer BUSY，输出极性与 GPIO 功能保持。原方案的七路外部反相晶体管适配不再用于 B1。外置 AO3400A 和 DHT 双向适配成品模块仍保留，不需要面包板。

板外形扩为125×100 mm，原四个安装孔90×90 mm孔距保留。右侧新增25 mm需与新版一体底座一起复核；本次 PCB 完成不能用作机械装配已通过的证据。

原理图通过结构化 kiutils 对象生成，PCB 通过 kicad-tool 项目扩展及 KiCad 原生对象 API 修改。原33段粗电源铜线保留并独立核对。剩余普通信号使用 Freerouting 后由 KiCad DRC 检查，局部残余连接作约束栅格补线；没有降低间距规则或忽略新违规。

第一轮 DRC 归零后，供电路径审计发现新去耦电容绕线偏长，调整C9—C15位置并手工预布供电脚和接地回路。最终每颗新缓冲器供电脚至去耦电容的铜线约2.33 mm，保留本地双地过孔。再次布线、铺铜、丝印整理后 DRC 归零。

最终数字检查：126个位号；372个连接管脚、8个NC；190接口端点；ERC零违规、DRC零违规、零未连接、零原理图差异。Gerber独立解析核对465个金属化孔和4个非金属化安装孔，位置误差最大0.00065 mm以内，属于导出小数位量化。

制造ZIP为7个板层加2个钻孔文件，手焊方案不包含钢网锡膏层。Gerbonara 对 KiCad G90头位置及RoundRect多余宏参数有解析警告；钻孔逐一匹配，图层已另行渲染检查。详细数字结果以 `checks/`、`review/` 中的最终报告为准。

未执行：制造下单、实物焊接、带载/温升/EMC测试、机械整机装配验收。原A1的双层局部回流绕行、C8位置和急停供电失效边界仍保留。不得把本版描述成完成实物验证。
