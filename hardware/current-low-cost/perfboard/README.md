# PWR和IO洞洞板参考布局

本目录是当前低成本单台方案的两块2.54mm独立焊盘洞洞板资料，配合[图解增强版Word](../../../docs/manual/)第61章使用。不是嘉立创PCB生产文件，也不能套用旧PCF8574底板针脚。

先读`00_先读我.txt`，再看元件面、焊接面和逐根焊线表。保持第1行朝上翻面，焊接面已经左右镜像；孔号仍指同一个物理孔，不能再次镜像。电机和舵机的动力回流直接回PWR。

两块板合计65个位号和142条默认连线记录。其中135条为绝缘飞线，7条为两根连续0.8mm汇流铜线的分段记录。CSV和`layout.json`保留精确孔号、网络和线规；跨线不表示电气连接。

先按实际洞洞板确认24列×30行有效孔区。商品模块仍在板外按丝印接线，自定义JCORE/JMCP等接口不能当作模块本身针序。图中默认未使用的AHCT第三通道如改作蜂鸣缓冲，按Word第61.8节及外接说明拆除相关原线、补回旁路，不能叠接。

已完成设计层面的孔位与网络检查，尚未使用实际器件焊接或通电验证。
