# SmartBin A — 手焊接口与配电 PCB

## Snapshot

2026-10-12 用户选择 A：裸 PCB 自焊，优先复用已购直插件及现成模块。100×100 mm 双层底板和制造包已完成，原理图 ERC 为 0 错误/0 警告，PCB DRC 为 0 违规/0 未连/0 一致性问题。它替代原 PWR/IO 两块洞洞板；数量由裸板报价选择，只装配一块。Word 与 Git 同步收尾记录见本次发布审核。

## Requirements

- 保持现有 STM32F103C8T6 / MCP23017 成品模块及全部已选功能的 GPIO 分配。
- 核心、MCP、TB6612、降压、3.3 V 稳压、传感器、RFID、FLASH、显示与通信模块外置；自定义接口用短杜邦线按信号名称连接，非商品模块直插插座。
- 复用 DIP14 AHCT 及插座、TO-92 NPN、1/4 W 轴向电阻、径向电容、2.54 mm 接口和 5.08 mm KF301 端子。
- 裸 AO3400A 先焊到独立转接板并接 G/S/D 线；条件 5 V 数字适配及 BSS138 双向转换保留在板外，并在接线表中逐项说明。
- 保持独立 3V3_CORE/3V3_EXT；共地。核心 USB 不连接，下载用 SWD / 3.3 V UART。
- 原电源：成品带保护 2S 电池，满电 8.4 V；外部保险及总开关；外置降压 5 V / 持续 3 A、短峰值至少 4 A。轮驱动与开盖分时运行。
- 设计电流约束：5 V 总线按 3 A 持续 / 4 A 短峰值；动力分支各按 2 A 预算；逻辑支路按 1 A 设计余量。具体器件、负载能力须实测，不把铜箔计算当实物验收。
- FR-4，2 层，1.6 mm，1 oz，绿色阻焊、普通喷锡；无需 SMT、钢网或贴片坐标采购。
- 四角 M3 非金属隔离柱固定，避开既有木板结构；PCB 安装孔定稿后再钻木板，不复用旧洞洞板孔号。
- 电路及 DRC 完成后导出源工程、原理图 PDF、Gerber/钻孔 ZIP、BOM、接口与装配图和上电检查。
- 图解增强版 Word 同名替换需保留 330 步并更新旧接线说明。完成校验后推送现有授权 GitHub 仓库。

## Architecture

电池 → 外置保险/总开关 → PCB 电池端与降压输入端 → 外置 5 V 降压 → PCB 5 V 配电 → 电机/舵机/逻辑独立支路。

逻辑 5 V → 核心自带 3.3 V 与外部 3.3 V 模块分别供电；两路稳压输出不并联。PCB 提供急停三管门控、AHCT 缓冲、电池和超声分压、照明外围电阻及信号接口。

## Validation / acceptance

1. 独立电气连接审查、器件真实脚序与供电核对。
2. ERC、原理图网表与机器规范逐脚一致。
3. 实体布局、散热/电流回路、可焊性、端子操作空间。
4. 布线全连通、DRC 实际报告、铜箔与正反面丝印审查。
5. Gerber + PTH/NPTH 钻孔审查；文件与源版本哈希一致。
6. Word 渲染 QA、根/仓库同名文档一致、Git 推送验证。

## Known physical limits

- 当前三管急停关闭轮电机驱动，未切断舵机电源；释放不续跑依靠固件故障锁。3V3_EXT 失电也使原钳位偏置消失，不声称新增完整硬件失效安全联锁。
- 5 V 模块 DO 不能直入 MCP；按实际模块测得电压选择外置适配。
- 未完成实焊、带载、温升、EMC 或机械整机验收；软件仓库不因换 PCB 自动成为可烧录完整固件。
