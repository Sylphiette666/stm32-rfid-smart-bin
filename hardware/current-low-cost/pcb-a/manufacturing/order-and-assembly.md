# SmartBin_A A1 裸板下单与手焊说明

本版用于一台课设样机，复用已经购买的直插件和成品模块。工厂制造裸 PCB，器件由你焊接；不选择 SMT/PCBA、不买钢网，也不重新购买一套贴片器件。

**2026-10-12：本版数字制造检查已通过。** 最终 PCB DRC 为 0 违规、0 未连和 0 原理图一致性问题；94 位号及每个引脚网络已与电气定义核对，最终 Gerber 已独立解析、检查双面图形并逐孔比对。证据见 `../review/release-evidence.json` 和 `../review/07-final-manufacturing-review.md`。实物未焊接、未通电，不能把设计检查当作样机验收。

## 1. 下单用哪个文件

上传本目录最终生成并核验的 **`Gerber_RS274X.zip`**。不要上传整工程压缩包、旧 V1/V2 Gerber、原理图 PDF、BOM 或截图作为裸板制造文件。工程用 KiCad 绘制，板厂按 Gerber 制造，无须先转换成立创 EDA 工程。

嘉立创官方说明要求 RS-274-X，并明确不支持 Gerber X2；本版按此格式输出。下单前仍需检查平台的生产预览和层识别。[嘉立创下单文件要求，2026-10-12 核对](https://www.jlc.com/portal/2/serviceGuide)

| 下单项 | 本版设置 |
|---|---|
| 产品 | 刚性 FR-4 裸 PCB |
| 板尺寸 | 100×100mm，以板框中心线尺寸为准 |
| 层数 | 2 层 |
| 板厚 | 1.6mm |
| 成品铜厚 | 1oz |
| 阻焊/字符 | 绿油/白字 |
| 表面处理 | 普通喷锡；按工厂选项选有铅或无铅喷锡 |
| 阻抗、盲埋孔、特殊工艺 | 无 |
| 拼板 | 单片板，不拼板 |
| SMT、PCBA、钢网 | 均不选 |
| 数量 | 只装一台；制板批次数量和价格按网站实际选项，不把装一台等同于工厂只做一块 |

平台预览应识别两层铜、双面阻焊、丝印、闭合板框和钻孔。确认 4 个安装孔、端子孔和排针孔都存在，尺寸没有变成 10×10mm 或英寸。核对生产稿中电源正负、插座缺口和 J 号；不要在平台自动改板框或合并电源网络。

## 2. 到货前先确认封装

打印最终元件面图时选 **100%/实际尺寸**，关闭“适应页面”。量一段已标尺寸后，把已有端子、IC 座和电解电容放上去核对。

板边“PIN 1 = SQUARE PAD”用于辅助识别 **J/JP 接口**。电解电容必须按 **“+”正极标记** 和接线表安装，不要把负极半圆丝印内的方形留白当成正极焊盘；C1–C3 的 1 脚接 5V、2 脚接 GND。

| 位置 | 本板设计 | 已购件核对方法 |
|---|---|---|
| J1–J6 | 2P、孔距 5.08mm、成品钻孔 1.3mm；Phoenix MKDS 库几何包络约 11.22×11.125mm | 通用 KF301 名称不能证明外壳兼容。核脚形能穿孔、相邻本体不挤、进线朝板边、螺丝刀可操作。并不要求重买 Phoenix 品牌。 |
| C1–C3 | 470µF/16V、1000µF/16V、100µF/16V；均预留 D12.5mm、P5.00mm | 按实物直径、脚距、极性检查。1 脚为正，2 脚接地；负极条纹对应负脚。脚距不合可用短绝缘整形引线并机械固定，不能悬挂大电容或强拉根部。 |
| U1 与插座 | SN74AHCT125N，DIP14，行距 7.62mm、针距 2.54mm | 先焊 1 只 DIP14 座，最后插 1 颗芯片。BOM 的 U1_SOCKET 是附件采购行，不是第二颗 AHCT 或第二个板上位置。 |
| Q1–Q3 | 2N3904，板端 1=E、2=B、3=C | 按所购厂商数据手册核脚序，不能只凭 TO-92 平面方向。不同脚序须绝缘整形、追线核对后再焊。 |
| R1–R37 | 1/4W 轴向位，脚距 10.16mm | 优先复用已有阻值；R1/R2、R25/R26 用 1%。条件位不一定实装。 |
| H1–H4 | 3.2mm 非金属化孔，四角距边 5mm | 孔中心距 90×90mm，使用 M3 绝缘立柱；螺钉/垫圈不压邻近铜箔或元件脚。 |

AO3400A 仍通过已购转接板接 J28，BSS138 双向电平转换板按需接 J23；本板没有要求重买这些裸贴片件。STM32、MCP、降压、3.3V 稳压、TB6612 和传感器都在板外单独固定。

## 3. 怎样使用 bom.csv

该表包含 **94 个 PCB 位号行，加 1 个 U1_SOCKET 附件行**。H1–H4 是机械孔，`Procure_if_missing=0`。`Quantity=1` 表示该位号的一处位置；不是让你重新买 94 个电气元件。所有原有器件优先复用，只有实际短缺或规格不合时才补购。

`DNP=YES` 表示默认不装；条件电阻要在测明模块已有上拉后决定。DNP 不是允许信号悬空。排针行的 DNP 与跳帽状态不同：排针需要焊，跳帽按下表放。普通器件的厂家、订单料号尚未确认，因此相关栏留空；这是一份手焊装配清单，不是可直接交给代贴厂的采购 BOM。

| 位置 | 默认与变更条件 |
|---|---|
| R8/R9 | 默认不装。全总线已有上拉须核并联值；若全无上拉，装 4.7k。I²C 上拉只能到 3V3_EXT。 |
| R10、R11/R12 | 默认安装，分别用于 MCP RESET、RC522/FLASH 片选。只有同轨已有合适上拉且验证后才可不装。 |
| R13/R14 | 默认不装。只有 FLASH 的 WP/HOLD 外露且模块未带合适上拉时安装。 |
| R27/R28 | 默认不装，保留已核编码器模块 EXT 上拉；若改用板上 CORE 上拉，先移除模块原上拉，再两只一起安装。 |
| R29 | 默认不装；DHT 低侧无有效同轨上拉时安装。5V DHT 还须转换板高侧上拉。 |
| R33 | 默认不装；编码器 SW 需模块同轨上拉、已验证 MCP 内部上拉或安装本电阻。 |
| R34/R35 | 默认安装，MODE/BACK 低有效。 |
| R36/R37 | 默认只装 R36 下拉。低有效蜂鸣先拆 R36，再装 R37 拉 CORE。不能同时装，也不能同时空；不用蜂鸣也保留一只，防 AHCT 输入浮空。 |

| 跳线 | 首次空载检查 | 运行选择 |
|---|---|---|
| JP3 蜂鸣信号 | 无帽 | 1–2：PB9 的 3.3V 直出；2–3：AHCT 的 5V 输出，只选一路 |
| JP4 蜂鸣电源 | 无帽 | 1–2：3.3V；2–3：5V，按模块额定 |
| JP5 MPU 电源 | 无帽 | 按实际模块 VIN 选 3.3V/5V；I²C 仍为 3.3V |
| JP6 HC05 电源 | 无帽 | 按裸模块或带稳压底板选择；UART 仍为 3.3V |
| JP7 DHT 电源 | 无帽 | 1–2：3.3V；2–3：5V，并满足 JP8 条件 |
| JP8 DHT 直连 | 无帽 | 仅已确认 3.3V DHT 时闭合；5V 时必须开且接 J23 转换板 |
| JP9 电池 ADC | 加帽 | 正常使用闭合；隔离核心前断整机电源，必要时先拔此帽隔离 ADC |
| JP10 MCP RESET | 无帽 | 仅临时短接到地测试复位，不长期加帽 |

JP1/JP2 已删除，其编号空缺是有意的。U1 第 3 通道固定使能，不执行旧洞洞板“五拆六增”。

## 4. 焊接和模块接线

1. 全部断电，不接 USB、电池、核心或传感器。先空插大件确认没有机械干涉。
2. 先焊固定电阻及小电容，再焊 DIP 座、三极管、排针、端子，最后焊电解。每组排针先焊一脚校直。U1 芯片暂不插。
3. 对照 BOM 查漏焊、连锡、阻值和极性。检查 VBAT/GND、5V/GND、EXT/GND 无持续短路；电容充电瞬间响不等于持续短路。CORE 与 EXT 不直接导通。
4. 按 `connector-map.csv` 和板上针号逐根接模块丝印。**33 组连接器是本项目板侧接口，不是商品模块排针次序。** 核心 J8/J9 也不能整排直插。
5. 核心由本板 5V 供电；3V3_CORE 与 3V3_EXT 只共地，不并联。正常系统不插核心 USB；下载走 SWD，电脑串口走 J18 三线且转换器供电脚不接。
6. 六路 IR 数字输入及 DFPlayer BUSY 先测电平。需要 5V 的 DO 在模块侧做已说明的 NPN 反相适配；板上 J33/J31 不是 5V 容忍口。AO 不经过 NPN，DHT 不经过单向转换。
7. 电池经外置保险和总开关到 J1，降压输入 J2、降压 5V 输出 J3。J4/J5/J6 分别供电机/舵机/逻辑。主干用短 20AWG，电机舵机短支路 22AWG，主电流不经普通杜邦线。
8. SG90 电源和主回流走 J5，PWM 走 J20.1；J20.1 是逻辑信号，不是电源。TB6612 的 VM/动力地走 J4，逻辑信号走 J19。近驱动/舵机和语音模块仍保留相应就地去耦。
9. AO 转接板按真实 G/S/D 接 J28，小 LED 按正负接 J29。DFPlayer 的扬声器直接跨 SPK1/SPK2，两端都不接地。
10. 电气通过后用四个绝缘立柱安装 PCB，遮护焊接面，线束两端贴信号名并做应力固定。

设计预算为 5V 持续至少 3A、短时峰值至少 4A；每个轮电机 5V 堵转电流应不超过 1A，两个电机与 SG90 动作分时互锁。3.3V 稳压的“至少 200mA”是已有材料下限，全部外设实测电流加余量仍须低于其实际能力。这些是设计条件，不是已经测得的数据。

急停经 STBY 使驱动输出高阻，车轮可能滑行；不切舵机电源。Q2 偏置依赖 EXT，EXT 失电而核心仍输出时不能保证相同硬件钳位。固件应撤使能/PWM并锁故障，异常可用总开关断电。两 3.3V 不并联也不代表所有 GPIO 已隔离；独立 USB 台架必须断板电源并拔全部核心线束，JP9 只隔离 ADC。
