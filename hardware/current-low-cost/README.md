# 当前制作方案

采用 STM32F103C8T6 核心板、MCP23017 扩展和洞洞板，复用已有模块。逐项装配以 [2026-10-10手册](../../docs/manual/ASSEMBLY.md) 为准。[接线表](WIRING.md) 用于查阅，不能代替上电前检查。

本目录是当前电路的接线设计资料，目前没有与此路线配套、已验证可直接打板的新 Gerber。旧版 PCB 在 `../archive/pcb-v2.1/`，使用 PCF8574，不能将两版引脚或程序混用。

机械图集中在 `../../docs/manual/source/`。当前活动盖用2 mm PVC、固定壳体用3 mm PVC、五片内胆用1 mm PP；具体公差、质量和机构行程须按手册实测。
