# 当前制作方案

采用 STM32F103C8T6 核心板、MCP23017成品扩展模块和PWR、IO两块洞洞板，复用已有模块。逐项装配见[330步阅读版](../../docs/manual/ASSEMBLY.md)，完整图解以[同名图解增强版Word](../../docs/manual/STM32与RFID智能移动垃圾桶_逐步组装与调试实施手册_图解增强版.docx)为准。[接线表](WIRING.md)和[洞洞板正反面、孔位及逐根焊线资料](perfboard/)用于查阅，不能代替实物核位和上电前检查。

本目录是当前电路的接线设计资料，目前没有与此路线配套、已验证可直接打板的新 Gerber。旧版 PCB 在 `../archive/pcb-v2.1/`，使用 PCF8574，不能将两版引脚或程序混用。

机械图集中在 `../../docs/manual/source/`。当前活动盖用2 mm PVC、固定壳体用3 mm PVC、五片内胆用1 mm PP；具体公差、质量和机构行程须按手册实测。
