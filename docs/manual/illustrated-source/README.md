# 图解增强版的图片与插入脚本

本目录保存首轮图解增强的图片与插入源：当轮在原手册基础上保留330个步骤、33项功能、43张表和原7幅图，加入30幅操作图解及1幅外观概念图。这些是首轮历史计数。后续SG90和洞洞板补充见[历史增量资料](../illustrated-additions-20261010/)及[洞洞板归档目录](../../../hardware/current-low-cost/perfboard/)；原版Word继续保留。

当前[同名图解增强版Word](../STM32与RFID智能移动垃圾桶_逐步组装与调试实施手册_图解增强版.docx)为198页，保留330个步骤，含57幅图、64张表；57幅图由49幅操作图解、1幅外观概念图和原7幅图组成。第63章采用A1裸PCB替代PWR/IO两块洞洞板，第61章保留为历史参照。新图45—49见[A1图解目录](../../../hardware/current-low-cost/pcb-a/diagrams/)，本轮手册更新源见[pcb-a-update-20261012](../pcb-a-update-20261012/)。页数及计数对应此次发布，后续增补须重新核验。

## 内容

- `figures/`：可直接插入Word的高清PNG，图内中文文字与示意线由脚本绘制。
- 四个`*_figures.json`：插入锚点、图下注释和替代文本。
- `diagram_common.py`与四个`build_*_figures.py`：绘图源程序。
- `enhance_manual.py`：读取原Word，按锚点插入图片，保留原操作段落和表格。

## 使用

在Windows安装了微软雅黑字体的环境中，使用含`python-docx`和`Pillow`的Python运行。现有PNG可直接复用，不必重新绘制。插入脚本支持`--input`、`--output`、`--concept`指定绝对路径；默认输入与输出为本目录上一层的两版Word，概念图在`docs/appearance/`。

本目录脚本只重建首轮插图，单独运行不能得到本轮最新Word，也不得直接覆盖最新交付文档。整合后须更新目录与页码、渲染并检查分页。绘图源中如需重新提取步骤标题，请使用原版Word的完整段落文字，不能用历史手册替代。

图解用于辅助操作：模块框的端子排列不代表实物针序；尺寸按文字数值，非等比例加工模板。验收结果仍由制作者实际测量填写。当前方案为MCP23017成品模块外置、100×100mm A1裸PCB手焊；旧双洞洞板图和PCF8574底板均只作归档，不混用接口位号和针序。
