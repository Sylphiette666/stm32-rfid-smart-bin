# SG90和洞洞板图解整合记录

本目录保存当轮加入同名图解增强版Word的9幅新增图及整合源。该轮历史版本为168页，保留330个步骤，共47幅图：原7幅图、39幅操作图解和1幅外观概念图；这些不是当前交付计数。

当前[同名图解增强版Word](../STM32与RFID智能移动垃圾桶_逐步组装与调试实施手册_图解增强版.docx)为198页、330个步骤、57幅图、64张表，其中57幅图为49幅操作图解＋1幅概念图＋原7幅图。第63章的A1裸PCB已替代PWR/IO两块洞洞板，第61章改作历史参照。新图45—49见[A1图解目录](../../../hardware/current-low-cost/pcb-a/diagrams/)，当前手册增量源见[pcb-a-update-20261012](../pcb-a-update-20261012/)。

## 在当轮历史手册中查阅

以下页码仅对应168页历史版；当前版本请使用Word目录定位同名章节。

- 第60章，第140—145页：舵机三线连接表；合盖0°、中间35°、全开70°；盖侧臂安装及舵盘球头连接。对应图解31—35。
- 第61章，第146—168页：PWR和IO元件面、焊接面，全部65个位号的孔位说明，51条PWR和91条IO默认连线记录，以及外置模块接线和分阶段通电。对应图解36—39。
- 原步骤附近已增加查阅索引，并同步AHCT选配通道、编码器上拉、PWR电池分压及外置AO3400A转接说明。

手册文件保持原名，位于本目录的上一级。后续新增图解继续更新该文件，不再另建一份名称相近的最终版。

## 文件内容

- `sg90/`：5幅SVG和高清PNG、图注与替代文本清单。
- `perfboard-print/`：4幅适合Word整页排版的SVG视口版本和PNG；保留完整孔号，不作为按打印尺寸划孔的模板。
- [完整洞洞板资料](../../../hardware/current-low-cost/perfboard/)：原始可放大SVG、PNG、CSV和结构化布局。
- `update_manual.py`：本轮增量编辑脚本。
- `integration_notes.json`：原文锚点及局部修订依据。
- `external_wiring_notes.json`：外置模块接线内容源。
- `compare_manual_structure.py`：原330步、既有图片及原表格的保留检查。
- `verification.json`：交付Word的校验值、内容计数和验证范围。

增量编辑脚本只适用于加入本轮9幅图**之前的139页历史图解增强版**，不能直接对已经含第60—61章及后续增补的当前版本重复运行。历史基线保留在Git提交`2f8f8e843177b4fc48536683c51c85c9d407cb23`中；使用显式`--input`和`--output`参数，并通过`--perfboard`、`--notes`传入本仓库对应源文件。生成后还需更新Word目录、渲染并实际检查各页。

## 验证边界

当轮已检查文档版面、原步骤保留、正反面坐标及连线表一致性。旧双洞洞板AHCT第三通道的蜂鸣器选配改线另做了网络连通性复核；其默认图和142条记录仍对应未启用该分支的状态，仅旧双洞洞板改接按Word第61.8节执行。A1 PCB第三通道已固定接线，按第63章选择跳帽，不执行旧“五拆六增”。本目录的verification.json及校验值也仅对应当轮输出。

这些检查不等于实物装配、通电或完整固件验收。模块物理针序和输出电平按到货实物核对；MCP23017是外置成品模块，核心也采用线束连接。
